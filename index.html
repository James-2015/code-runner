        加速原理：

        • 判题时用 Judge0 Batch API，把所有测试点打包成一次 HTTP 请求提交，轮询时也批量查询，网络往返从 2N 次降到 2 次。

        • 自由运行仍用单次提交，但轮询间隔激进（50ms 起，指数退避至 800ms）。

        • 语言列表来自 Judge0 CE 官方 /languages 端点，共 60+ 种，这里精选了常用和经典语言。

        • CORS 提醒：Judge0 CE 公共实例的 CORS 策略在不同网络环境下表现可能不一致。如果浏览器控制台报跨域错误，说明您的网络被拦截，需要代理或自建 Judge0。
